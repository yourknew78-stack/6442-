# COMP2100／6442 零基础复习手册

依据 `考点整理.png` 的七项考点与优先级编写。每章先讲零基础知识和短例，再用带编号的真题讲解巩固。

## 使用方式

1. 按优先级顺序学习；时间不足时先读每章的知识点和最近年份题。
2. 知识讲解中的 Java 示例较短，先亲手推演输入与输出，再看代码。
3. 真题保留英文题干、必要原始代码／数据、来源路径和原始图示；中文解析与非官方参考答案直接放在题后。
4. 跨考点题在相关章节完整重复，方便按单章独立复习。
5. Mermaid 图需要支持 Mermaid 的 Markdown 阅读器；不支持时仍可读原图与文字解释。

## 标题与答案约定

```text
章标题
├─ 第一部分：知识点的零基础学习
│  ├─ 知识点 1
│  └─ 知识点 2
├─ 真题讲解 1
│  ├─ 1.1 题目原文
│  ├─ 1.2 分析
│  └─ 1.3 参考解答
└─ 真题讲解 2
```

- 真题以 2023–2025 六套题为主；某子考点缺少近年直接题时补早期真题。
- `past-exams` 均无直接题的子考点使用 `misc-questions`，并明确标为“仓库补充练习，非真题”。
- 所有答案均为**非官方参考解答**。开放题通常不唯一，应学习证据组织和论证方式，而不是逐字背诵。
- 分支覆盖采用课程常见口径：`&&`、`||` 的短路子条件也纳入分析。
- 树高度必须看题目定义；本手册遇到题目时会明确按层数还是边数。

## 验证情况

- 在 Java 25、JUnit 4 环境下，参考实现的 **127 个正向 JUnit 测试通过**，另通过数学非法输入和 Markdown 末尾空白行检查。
- AVL 测试数据在正确不可变实现上 4 组全过；原题提供的非平衡 `SampleAVLTree` 则 4 组如预期失败。
- HashingBox 的 130 个参数化测试中，`HashingBox10` 全过，其余 12 个实现均至少被一个规格用例抓出；测试包含首六字符与 ASCII 标点边界。
- Markdown 的相对链接、图片路径、代码围栏、知识部分和真题编号均通过自动检查。
