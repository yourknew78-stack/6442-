public static Integer calculatePrice( int unitPrice, Integer quantity, String memberId) { double discount = 0.0; if (quantity == null) { discount -= 0.2; quantity = 1; if (memberId == null || memberId.trim().isEmpty()) discount -= 0.1; } if (quantity <= 3) return unitPrice * 4; else if (quantity >= 5) { if (List.of("id1", "id2", "id3").contains(memberId) && unitPrice >= 3) return 10; else if (quantity / 6 >= 1) quantity -= quantity / 6; } return (int)(unitPrice * quantity * (1 - Math.min(discount, 0))); }
1.3 参考解答 · 非官方

1.3.1 先画分支，再倒推最小用例

  1. 列出每个判断的真、假出口，特别注意 null 会把数量改为 1。
  2. 把每个分支出口写到覆盖表，合并能一次走过多个未覆盖出口的用例。
  3. 计算期望值时必须沿原代码执行，不按“业务上是否合理”改写规则。
判断点需要覆盖用例设计提示
quantity == nulltrue / falsenull 与非 null 各至少一次
会员为空判断true / false只在数量为 null 时可达
quantity <= 3 等后续判断所有可达出口正式版给出完整覆盖矩阵与最小性说明
