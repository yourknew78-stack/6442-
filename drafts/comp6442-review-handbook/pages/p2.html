分词与递归下降：先学会把输入切开，再学会检查结构。

二级标题 · 第一部分：知识点的零基础学习
知识点 1 · 必要前置基础

1.1 类、枚举、异常与递归

Token 用对象保存“类型＋原文”；TokenType 用枚举限制类型；遇到非法输入时抛出异常；Parser 用递归处理嵌套括号。

知识点 2 · Tokeniser

2.1 把字符序列切成有意义的 Token

例如输入 1 + 2 * 3，分词器不计算答案，只输出下面这些小单元：

INT
"1"
PLUS
"+"
INT
"2"
TIMES
"*"
INT
"3"
Token t = new Token(TokenType.INT, "1"); // type 告诉 Parser“这是什么”，value 保留原始文本
知识点 3 · 文法与递归下降

3.1 先写规则，再写方法

Exp → Term (("+" | "-") Term)* Term → Factor (("*" | "/") Factor)* Factor → INT | "(" Exp ")"

每条规则对应一个方法；parseExp() 调用 parseTerm()，因此乘法自然比加法先结合。

3.2 每个方法只负责一种结构

Exp parseExp() { Exp left = parseTerm(); while (match(PLUS)) { Exp right = parseTerm(); left = new OpExp(left, right, PLUS); } return left; }

知识点 5 · 易错点
  • 分词时不应顺手计算表达式。
  • 读取下一个 Token 前先检查是否越界。
  • 括号内解析结束后必须消费右括号。
  • 无法匹配文法时给出明确异常。
