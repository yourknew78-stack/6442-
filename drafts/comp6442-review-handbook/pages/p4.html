1.3 英文示范答案 · 可直接模仿答题结构

1.3.1 Principle 1 — Single Responsibility Principle

Definition. A class should have one reason to change.

Violation. MDToken represents ordered and unordered list elements while also storing type-specific state such as number. Changes to one list representation can therefore affect unrelated clients of the other representation.

Example. If ordered-list numbering changes, code handling unordered items may still need to be recompiled and retested because both representations share the same class.

Refactoring. Introduce separate ordered and unordered token implementations behind a common abstraction, keeping only shared state and behaviour in the parent type.

中文分析：答案按“定义 → 代码证据 → 具体后果 → 改法”展开，而不是只写原则名称。正式版会同样完整回答第二项原则。

1.4 评分点拆解
概念准确用自己的话解释原则，不背错定义。
