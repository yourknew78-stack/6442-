组合、聚合、继承与多重性

真题讲解 1：UML Class Diagram

来源：past-exams/2024-1/src/Q4/Q4README.md　｜　原图：UML-MCQ9.png
1.1 题目原文

Considering the class diagram below, which alternative is INCORRECT?

1.2 原始图片 · 完整保留
原图占位：UML-MCQ9.png
ParkingLot / Floor / Spot / Vehicle
Car / Motorcycle
正式版复制到本手册 assets 目录
1.3 Mermaid 重绘 · 配合中文读图
ParkingLot ◇── 0..* Floor
Floor ◆── 1..* Spot
Spot ◇── Vehicle
Vehicle ◁── Car / Motorcycle
逐个解释菱形、箭头与 1 / 0..*
1.4 原始选项 · 英文保留
A. The relationship between Floor and Spot is a composition. It means that if an instance of Floor is destroyed the Spot instance must also be destroyed.
B. Car is a Vehicle and Motorcycle is a Vehicle. This relationship is an aggregation.
C. One ParkingLot has zero or many instances of Floor.
D. Vehicle is the parent class of Motorcycle and Car… the attributes name and color are private…
1.5 参考答案与逐项解析 · 非官方
答案：B

A 正确：Floor 与 Spot 之间是实心菱形，表示组合，生命周期由整体控制。

B 错误：Car、Motorcycle 指向 Vehicle 的三角箭头表示泛化（继承），不是聚合。

C 正确：ParkingLot 一端的 1 与 Floor 一端的 0..* 对应“一个停车场可有零或多层楼”。

D 正确：子类继承公开操作；父类中的 - name 与 - color 表示 private。
